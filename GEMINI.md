# Gooni Gooni (MediaGen) — Project Context

## Project Overview
Gooni Gooni (also referred to as MediaGen) is a full-stack web application for AI-powered image and video generation. It features a modern React frontend and a serverless Python backend powered by Modal for high-performance GPU inference.

### Core Technologies
- **Frontend:** React 18, Vite 6, TypeScript, TailwindCSS 4, Radix UI, Motion (Framer Motion).
- **Backend:** Python 3.11, FastAPI, Modal (Serverless GPUs), Diffusers, Transformers, SQLite.
- **Infrastructure:** Docker, Nginx (as a reverse proxy and static file server), GCP (Google Cloud Platform).

## Architecture
The application follows a decoupled architecture:
1.  **React SPA (Frontend):** Serves the user interface for prompt engineering, model selection, and gallery management.
2.  **FastAPI on Modal (Backend):** Handles API requests and executes GPU-intensive tasks (image/video generation) using serverless functions.
3.  **Storage:** SQLite (stored on Modal volumes) for task metadata and a gallery database. Files (images/videos) are also stored on persistent Modal volumes.

### AI Models Supported
- **Video:** AniSora V3.2 (Anime), Phr00t WAN 2.2 (Realistic).
- **Image:** Pony Diffusion V6 XL (Anime), Flux.1 [dev] (Realistic).

## Directory Structure
- `src/`: React frontend application.
    - `app/`: Components, pages, and state management logic.
    - `styles/`: Tailwind and global CSS.
- `backend/`: Python backend application.
    - `app.py`: Main entry point (FastAPI + Modal app).
    - `models/`: Pipeline implementations for different AI models.
    - `storage.py`: SQLite gallery and task management.
    - `tests/`: API smoke tests.
- `guidelines/`: Project-specific AI instructions and coding standards.
- `dist/`: Built frontend assets (generated by `npm run build`).

## Building and Running

### Frontend
- **Install Dependencies:** `npm install`
- **Development Server:** `npm run dev`
- **Production Build:** `npm run build`

### Backend (Modal)
- **Install Modal CLI:** `pip install modal`
- **Setup/Auth:** `modal setup`
- **Deploy:** `modal deploy backend/app.py`
- **Tests:** `pytest backend/tests/test_api.py`

## Development Conventions
- **Styling:** Use TailwindCSS 4 for layout and components. Refer to `UI_STRUCTURE.md` for the design system.
- **Animations:** Use `motion/react` (Framer Motion) for transitions and interactive effects.
- **State Management:** React Context (e.g., `GalleryContext`) for global state.
- **API Communication:** Use the `X-API-Key` header for authentication.
- **Environment Variables:**
    - `VITE_API_URL`: URL of the deployed Modal backend.
    - `VITE_API_KEY`: Authentication key for the API.
    - `VITE_ADMIN_KEY`: Authentication key for the admin panel.
